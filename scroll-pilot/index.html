Scroll pilot

A five-step scroll story built with Next.js and three.js. This page is the always-available companion: the storyboard, the setup, and — once the preview has been built locally — a link straight to the live export.

Storyboard

  1. Hero. The green head floats in its wire ball under the Healthier headline, which rises word by word while the ask button fades in.components/ScrollPilot.jsx
  2. Pull back. The camera eases to a tight isometric view on the r of “research”. Characters roll along paths that are secretly letter outlines — too close to read.lib/scene.js · lib/letters.js
  3. Track. The camera tracks along the line from the r in “research” to the r in “your”, scrubbed by scroll over five screens.scroll-scrubbed camera move
  4. Aerial. Straight overhead: the balls become coloured dots and the paths read as “A world of research on your case.”KMR Melange Grotesk outlines → ground paths
  5. Fill. The type fills in.final step

The sentence is set in licensed KMR Melange Grotesk (opentype.js turns each glyph into closed paths). Details: scroll-pilot/README.md.

Setup

The live preview is a generated static export in scroll-pilot/preview/. It is git-ignored, so a fresh checkout needs three steps:

# 1. licensed fonts — copy the two KMR Melange Grotesk .otf files into
#    public/fonts/ (see public/fonts/README.md; not committed)

# 2. install + build the static export
npm ci
npm run build          # writes out/

# 3. relativize for browsing from any folder
python3 relativize.py out preview

To hack on it instead: npm run dev serves the app at http://localhost:3000. Node 18+ recommended; the lockfile pins Next 15 / React 19 / three r170.
