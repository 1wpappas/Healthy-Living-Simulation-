# Fonts go here

The scroll pilot sets its sentence in **KMR Melange Grotesk**. The font files are licensed and are not committed to this public repo.

Copy these two files from the `healthier` repo (`public/d1/fonts/`) into this folder before running:

- `KMRMelangeGrotesk-Regular.otf` (used for the headline and for the letter paths)
- `KMRMelangeGrotesk-Medium.otf`
