# Fonts (not in the repo)

The hero sim uses licensed ABC Diatype fonts. They aren't committed. Put these three files in this folder to see the page as designed:

- `ABCDiatype-Regular.otf`
- `ABCDiatypeRounded-Black-Trial.otf`
- `ABCDiatypeMono-Regular-Trial.otf`

Without them the page falls back to system fonts. You can also pick another font in the dial kit (Type section).
